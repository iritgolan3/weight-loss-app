=====================================================
  VISIONTRACK - הפעלה ידנית (עוקף חסימת ווינדוס)
=====================================================

אם ווינדוס חוסם את START-HERE.bat
("בקרת אפליקציות" / SmartScreen / "Windows protected your PC")
יש שתי דרכים. נסה קודם את דרך 1 - היא הכי פשוטה.


=====================================================
  דרך 1 - לבטל את החסימה של הקובץ
=====================================================

ווינדוס מסמן כל קובץ שהורד מהאינטרנט כ"חסום".
צריך להסיר את הסימון מקובץ ה-ZIP לפני החילוץ.

1. למחוק את התיקייה שכבר חילצת.

2. לחיצה ימנית על VisionTrack.zip
   (על ה-ZIP עצמו, לא על מה שבפנים)

3. Properties  (מאפיינים)

4. למטה, ליד Security, לסמן V על:
   Unblock   (בטל חסימה)

5. Apply  ואז  OK

6. עכשיו לחלץ שוב, ולהפעיל את START-HERE

אם עדיין חסום - תעבור לדרך 2.


=====================================================
  דרך 2 - להקליד את הפקודות (תמיד עובד)
=====================================================

ווינדוס חוסם קבצים, לא פקודות שמקלידים.
לכן זה עוקף את החסימה לגמרי.

** צריך Python מותקן. אם אין:
   python.org/downloads
   חשוב! לסמן V על "Add python.exe to PATH"
   בזמן ההתקנה.

** Node.js לא צריך. הממשק כבר בנוי בתוך הקובץ.


שלב 1 - לפתוח שורת פקודה בתיקייה הנכונה
----------------------------------------
א. להיכנס לתיקייה שחילצת
   (זו עם START-HERE ו-backend בתוכה)

ב. ללחוץ על שורת הכתובת למעלה
   (איפה שכתוב הנתיב של התיקייה)

ג. למחוק מה שכתוב שם, להקליד:

      cmd

ד. Enter

נפתח חלון שחור. מצוין.


שלב 2 - להעתיק את 3 הפקודות
----------------------------
להעתיק כל שורה, להדביק בחלון השחור, ו-Enter.
אחת אחרי השנייה - לחכות שכל אחת תסיים.

שורה 1 (מהירה):

python -m venv backend\.venv

שורה 2 (איטית - 5 עד 10 דקות, מוריד הרבה):

backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt

שורה 3 (מפעילה את התוכנה):

backend\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --app-dir backend


שלב 3 - לפתוח בדפדפן
--------------------
כשכתוב בחלון השחור:

    Uvicorn running on http://127.0.0.1:8000

לפתוח דפדפן ולהיכנס לכתובת:

    http://localhost:8000

המצלמה תתחבר ותתחיל לנתח לבד.


=====================================================
  בפעמים הבאות
=====================================================

לא צריך לחזור על הכל. רק:

1. לפתוח cmd בתיקייה (כמו בשלב 1)
2. להדביק רק את שורה 3
3. לפתוח http://localhost:8000


=====================================================
  בעיות
=====================================================

"python is not recognized"
   Python לא מותקן, או לא סומן "Add to PATH".
   להתקין מחדש מ-python.org/downloads
   ולסמן את התיבה הזו.

"No module named uvicorn"
   שורה 2 לא הסתיימה בהצלחה. להריץ אותה שוב.

הדפדפן אומר "No camera found"
   אין מצלמה מחוברת, או תוכנה אחרת תופסת אותה
   (זום / טימס / אפליקציית המצלמה). לסגור אותן ולרענן.

לעצור הכל
   Ctrl+C בחלון השחור, או פשוט לסגור אותו.
