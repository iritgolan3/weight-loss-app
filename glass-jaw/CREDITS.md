# Credits

**GLASS JAW — Championship Boxing**

An original arcade boxing game. Everything you see and hear while playing is
generated by the code in this repository at runtime.

---

## What this game is made of

### Art — 100% procedural, 0 files

There are no images in this project. Not one PNG, JPG, SVG or sprite sheet.

Every fighter, arena, crowd member, glove, particle and menu panel is drawn
with Canvas 2D vector calls at the display's native resolution, from data:

| Thing | Where it comes from |
|---|---|
| Fighter bodies, faces, hair, trunks, gloves | `src/render/FighterRenderer.ts` driven by the `Appearance` spec on each boxer |
| Poses and animation | `src/anim/poses.ts` — procedural, derived from combat frame data |
| Ring, ropes, posts, mat, crowd, lighting | `src/render/ArenaRenderer.ts` |
| Impact effects, sparks, shock rings, callouts | `src/render/VFXManager.ts`, `src/render/ParticleSystem.ts` |
| HUD, menus, bars, stars | `src/ui/` |

Because the art is vector and resolution-independent, it is genuinely
high-resolution at any display size — including 4K and beyond — rather than an
upscaled bitmap.

### Audio — 100% synthesized, 0 files

There are no audio files in this project. No WAV, MP3, OGG or samples.

| Thing | Where it comes from |
|---|---|
| Punches, blocks, parries, whooshes, knockdowns | `src/audio/Synth.ts` — shaped noise plus oscillators |
| The bell | Six inharmonic sine partials with a long decay |
| Crowd | Band-limited noise with an amplitude envelope |
| Fighter voices and the referee's count | Sawtooth through resonant band-pass filters (formant-style) |
| All eleven music tracks | `src/audio/MusicEngine.ts` — original note patterns played by a lookahead step sequencer |

### Fonts

System fonts only, requested through CSS generic families
(`Impact, "Arial Black", system-ui, sans-serif`). No font files are bundled or
downloaded, so there is nothing to license.

### Characters and writing

All sixteen boxers, the player character, their names, nicknames, nationalities,
biographies, personalities, quotes, fighting styles and weak points were written
for this game. Any resemblance to a real person is unintended.

## A note on inspiration

Glass Jaw is an original game that admires a genre: the one-on-one arcade boxing
game, where you beat an opponent by *reading* them rather than by out-mashing
them. That genre's conventions — a single opponent framed centrally, a
foreground player seen from behind, telegraphed attacks, counter windows, a
reward meter, knockdowns and a ten-count — are gameplay ideas, and this game
implements its own versions of them.

Its characters, art, animation, music, sound effects, dialogue, interface, code
and assets are original to this project. Nothing here is copied, traced,
sampled, decompiled or ported from any other game.
