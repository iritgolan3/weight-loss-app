# Beit Biram Campus — 3D Reconstruction

A procedurally generated 3D model of the **Hebrew Reali School, Beit Biram campus**
(בית הספר הריאלי העברי – קמפוס בית בירם), 15 Abba Hushi Ave, Haifa, Israel.

Everything — terrain, buildings, pergola, vegetation, materials, lighting and
cameras — is generated by Python from scratch. There are no external assets and
no texture files: `out/beit_biram.blend` is fully self-contained.

---

## ⚠️ Read this first: how accurate is it, really?

**This model could not be built from imagery, and you should not treat it as a
survey-accurate digital twin.**

The session that produced it ran behind a network egress policy that permitted
only package registries. Every source that would have pinned the geometry down
was unreachable:

| Source | Status |
|---|---|
| `reali.org.il` — the **official interactive campus map** and the campus **PDF map** | blocked |
| `he.wikipedia.org` / `en.wikipedia.org` / Wikimedia Commons | blocked |
| OpenStreetMap (Overpass / Nominatim) — building footprints | blocked |
| Satellite and aerial imagery, street-level photography, all photo sources | blocked |

The only channel that worked was **web search**, which returns page summaries and
quoted text but **no images and no geometry**. So:

* The **facts** below are all sourced and cited in [`REFERENCES.md`](REFERENCES.md).
* **No photograph, map or aerial image was ever consulted.** Nothing here is traced.
* Footprints, dimensions, storey counts and window grids are **reconstructions**
  consistent with the documented record — not measurements.

### What is documented (tier A — from cited sources)

* Which buildings exist, their **names, dates and functions**:
  Biram Building (**1939**, **International Style**, first on campus) · Wolfson
  (**two phases, late 1980s**) · Prat (**2002**, for the 12th grade, **linked to
  Biram by a covered bridge**) · Landes · Pevzner Hall
  (**1962**, architect **Prof. Yohanan Ratner**, **650 seats**, **suspended concave
  roof**) · Library / Menachem Reich (**1967**, **shaded by a horizontal concrete
  slab attached to it**, houses the Yoel Angel hall) · Computer & communications
  centre (**1955**, ex-physics labs) · science complex · sports complex (**1955**:
  football stadium and parade ground, basketball courts, sports hall, **indoor
  swimming pool**, fitness room) · pedagogical complex · **Ruach ve-Re'ut**
  (inaugurated **31 Aug 2022**) · archive (1995 / building 2004).
* **Relative layout**: the library, computer centres and science complex lie
  **west of the Biram Building, toward the entrance**; **Wolfson, Landes and Prat
  lie north-east of the Biram Building**; the **sports complex is at the northern
  end**, with the pedagogical complex and Ruach ve-Re'ut **beside it**.
* **שדרת הפרגולה** — a **pergola avenue links most of the buildings** with covered
  passage between them. Modelled as the campus's organising spine.
* A **concrete wall surrounds the campus** to keep out the noise of the busy
  adjacent road, cutting the lawns off from the city.
* **Brutalist buildings of bare, unplastered concrete, decorated with symbols**,
  each specialised building according to its field of knowledge.
* **Wide lawns** between the buildings.
* A **memorial wall outside the library** with plaques naming the school's
  **306 fallen**, plus a digital information screen.
* Site **~50 dunam**, on **Mount Carmel** between **Abba Hushi Blvd, Einstein St
  and Yaarot St** in Upper Ahuza. *(Model site = 50.5 dunam.)*

### What is reconstructed (tier B — reasoned, not measured)

Building footprints and their exact positions; storey counts and floor heights;
window grids, sizes and proportions; structural bay spacing; roof and parapet
details; the specific route of the pergola; the terrace levels and the retaining
walls; which street runs on which side (the entrance is placed on the Abba Hushi
frontage because the sources put the entrance cluster *west* of the Biram Building).

### What is generic dressing (tier C — not claimed to match reality)

Individual trees, benches, bins, lamps, bollards, bike racks, planting beds,
paving patterns, kerbs, manholes, parked cars and the neighbouring houses. The
Brutalist relief panels are **abstract** — the real motifs are documented to
exist but are described nowhere reachable, so inventing specific emblems would
have been a fabrication.

**If you have photographs or the official map, the model is built to be corrected.**
See *Correcting the model* below — the layout lives in one small data file.

## Quick start

```bash
pip install bpy==5.0.1                 # Blender as a Python module (needs Python 3.11)
python3 scripts/build.py               # writes out/beit_biram.blend  (~6 s)
python3 scripts/render.py --cams ALL   # writes renders/*.png
python3 scripts/check_cameras.py       # verifies no camera is inside geometry
```

`build.py` is deterministic: same input, same model, every time.

If Blender renders come out washed out and colourless, the PyPI `bpy` wheel has
not been pointed at its own OCIO config. `scripts/lib/core.py` sets `$OCIO`
automatically on import; if you bypass it, export it yourself:

```bash
export OCIO=$(python3 -c "import bpy.utils;print(bpy.utils.resource_path('LOCAL'))")/datafiles/colormanagement/config.ocio
```

### Options

| Command | Effect |
|---|---|
| `build.py --out path.blend` | write somewhere else |
| `build.py --light` | fewer render samples / bounces, for fast iteration |
| `build.py --lite --out out/beit_biram_lite.blend` | thinned planting for a lighter viewport scene — same layout, fewer instances |
| `build.py --context` | **also** build the surrounding streets, pavements, kerbs, neighbouring blocks and wooded hillside (off by default) |
| `render.py --cams CAM_01_MainEntrance,CAM_05_AerialOverview` | render selected cameras |
| `render.py --samples 256 --res 2560x1440` | final-quality stills |
| `variants.py` | writes `beit_biram_{morning,golden,sunset,evening}.blend` |
| `variants.py --only golden` | just one lighting variant |

`variants.py` re-lights the saved scene at real Haifa sun angles for each hour
(morning, golden hour, sunset, dusk) and turns the campus lighting up after dark.
Daylight is the reference setup and lives in `build.py`; these are extras.

## Scope

**The deliverable is the school itself.** The default build stops at the campus
boundary: the walled site, its buildings, grounds and planting, plus a modest
apron of hillside so the campus sits in ground rather than ending at a cliff.

The surrounding streets (Abba Hushi / Einstein / Yaarot), their pavements and
kerbs, the neighbouring Ahuza blocks and the wooded Carmel hillside beyond are
built **only** with `--context`. They roughly double the triangle count.

## What is in the scene

```
BEIT_BIRAM/
  TERRAIN/          heightfield + RETAINING/ (terrace walls, steps, ramps)
  BUILDINGS/        SCIENCE_COMPLEX, ARCHIVE, OPEN_UNIVERSITY, SPORTS_HALL,
                    PEDAGOGICAL, RUACH_VERE_UT, KINDERGARTEN, MAINTENANCE, GATEHOUSE
  HISTORIC_BUILDINGS/ BIRAM_BUILDING, PEVZNER_HALL, LIBRARY_REICH, COMPUTER_CENTRE
  BOUNDARY/         the concrete acoustic wall, palisade fencing, gates, turnstiles
  PATHS/            paved surfaces + PERGOLA/ (שדרת הפרגולה)
  VEGETATION/       HERO_TREES/ TREES/ BUSHES/ GRASS/
  FURNITURE/        benches, bins, bike racks, memorial wall, sports equipment, cars
  SIGNS/            sign boards + Hebrew 3D text
  LIGHTING/         sun + lamp columns, bollard lights, stadium floodlights
  CAMERAS/          8 views + REFERENCE_CAMERA
  SURROUNDINGS/     --context only: STREETS/ NEIGHBOURHOOD/ HILLSIDE/ STREET_TREES/
  _TEMPLATES/       hidden instance sources (vegetation)
```

**Scale is real**: 1 Blender unit = 1 metre. Campus 250 × 202 m ≈ 50.5 dunam.

**Scene cost**: ~4.6 M triangles from ~75 unique meshes in a ~13 MB file. Trees
are linked duplicates on two levels of detail: instances more than 95 m from every
ground camera use a leafless variant, roughly halving their cost, while anything a
camera can actually see up close keeps its leaf cards. `--context` roughly doubles
the scene.

### Signature elements

* **Pevzner Hall's suspended roof** is real geometry: a parabolic deck hung
  between two deep edge beams on raking buttress fins, dishing 4.7 m over a
  36 m span, with the catenary curve exposed on the gable ends and ribs on the
  soffit.
* **The pergola avenue** runs the length of the campus with branches to each
  building group — concrete posts, longitudinal beams and a slatted top that
  throws the characteristic ladder of shadow.
* **The library's horizontal shading slab** is a deep, slotted concrete plane on
  its own row of columns, standing clear of the glazed south elevation.
* **The Biram Building** carries the International Style vocabulary: continuous
  ribbon windows, flat roof with a thin parapet, a cylindrical stair drum with a
  vertical glazed slot, cantilevered balconies on slim pipe railings.
* **The concrete acoustic wall** is built as discrete cast panels between proud
  pilasters, following the terrain, broken only at the gates.

### Windows are assemblies, not rectangles

Every opening is punched as real geometry and lined with reveal faces, then
filled with a frame, mullions and transoms, glazing, a projecting sill and — where
the building type calls for it — external louvres or a roller-shutter box. Behind
the glass sits a shallow dark interior recess, so a window reads as a room rather
than a hole through a hollow shell.

### Materials

36 procedural PBR materials, all node-based, all driven from **world-space
coordinates** so one Blender unit is one metre on every surface: board-marked
béton brut at true 0.62 m shutter spacing, coursed limestone, 0.5 m paving slabs,
asphalt, lawn, soil, Carmel rock, polyurethane track, synthetic turf, water, bark
and foliage with subsurface scattering. Wall bases pick up a height-driven
weathering gradient.

### Lighting

Haifa daylight at ~52° elevation from the SSW (the campus is at ~32.8° N), a real
0.53° solar disc for crisp shadows, and Blender's physical sky. The sky is split
by a Light Path node: camera rays see it at full strength so it looks like a
Mediterranean sky, while diffuse rays get a dialled-back version — a physical sky
bright enough to *look* right will otherwise flood the scene and erase every
shadow. Colour management is AgX.

## Correcting the model

The whole layout is data in one file: **`scripts/lib/siteplan.py`**. To move a
building, change its `rect` (x0, y0, x1, y1 in metres) and `floors`, then re-run
`build.py`. Terraces, sports pitches, parking, the pergola route, the paths and
the gates are all in the same file.

Working from a photograph:

1. Point `REFERENCE_CAMERA` at the same viewpoint (it exists for exactly this).
2. `python3 scripts/render.py --cams REFERENCE_CAMERA`
3. Compare, adjust `siteplan.py` (or the relevant builder in
   `scripts/lib/buildings.py`), rebuild, repeat.

`scripts/check_cameras.py` will tell you if a camera has ended up inside a wall
or a tree crown.

### Where the code lives

| File | Contents |
|---|---|
| `scripts/build.py` | orchestrator: assembles the scene and saves the .blend |
| `scripts/render.py` | batch renderer |
| `scripts/check_cameras.py` | camera obstruction validator |
| `scripts/variants.py` | alternative lighting setups (golden hour, sunset, dusk) |
| `scripts/lib/siteplan.py` | **the site plan — layout data, edit this first** |
| `scripts/lib/terrain.py` | terraced Mount Carmel heightfield, retaining walls |
| `scripts/lib/buildings.py` | one builder per building + the facade system |
| `scripts/lib/arch.py` | windows, doors, railings, stairs, pergola, brise-soleil, services |
| `scripts/lib/materials.py` | 36 procedural PBR materials |
| `scripts/lib/veg.py` | Mediterranean species generators |
| `scripts/lib/props.py` | site furniture, boundary walls, gates, sports kit, cars |
| `scripts/lib/core.py` | mesh builder, walls-with-openings, collections, instancing |
